# 샘플 프로젝트 핸드오프 — "아침 날씨 한 줄" (플로우 자가 검증용, 실제 개발 아님)

## 배경
이 저장소의 7단계 플로우가 프로젝트 내용 없이도 혼자 서는지 확인하려는 가짜 프로젝트다. 1단계(기획 → 기획 리뷰 → 게이트 기록)만 돈다.

## 요청
매일 아침 7시에 서울 날씨를 한 줄 문장으로 만들어 텍스트 파일에 덧붙이는 작은 도구. 외부 날씨 API 하나를 읽기만 한다. 3주 운영으로 증명한다.

## 범위
- 포함: 날씨 조회, 문장 생성(LLM 0 — 틀 문장), 파일에 덧붙이기
- 제외: 알림 발송, 웹 화면, 다른 도시

## 성공 기준(초안)
- 21일 중 빠진 날 0일
- 문장의 기온·강수 숫자가 API 응답과 일치(불일치 0건)
- 실행 시각이 07:00 ± 5분

## 지킬 선
- API 키는 환경 변수로만, 로그에 찍지 않는다
- 파일은 덧붙이기만, 지우지 않는다

## 미정
- 날씨 API 제공사 — 대표가 정한다
